# Estudos de POO com C#

Repositório dedicado aos meus estudos de Programação Orientada a Objetos utilizando C# e .NET.

## Objetivo
Praticar conceitos fundamentais de POO através de exercícios e pequenos sistemas.

## Conceitos praticados
- Classes e objetos
- Encapsulamento
- Métodos
- Construtores
- Propriedades
- Bool e validações
- Regras de negócio
- Separação de responsabilidades

## Exercícios
### Conta Bancária
Refatoração da lógica inicial para:
- remover responsabilidades desnecessárias da classe
- melhorar encapsulamento
- simplificar fluxo de saque
- utilizar construtor para garantir estado válido
- separar lógica da aplicação da lógica da entidade

## Tecnologias
- C#
- .NET
